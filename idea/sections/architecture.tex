\section{System Architecture}
Our proposed testbed has been formulated as a closed-loop simulation environment to facilitate testing an autonomous vision-based rendezvous of a spacecraft Chaser to a mobile Target spacecraft or debris. To support efficient testing and validation, the simulation architecture is divided into four individual modules: the Dynamics module, the Perception module, the Estimation module, and the Guidance-and-Control module. Such a modular setup not only facilitates individual assessment and validation of the separate components, but also allows their collective interaction and performance evaluation within the complete rendezvous loop. The system architecture including the overall information flow is detailed in Fig.~\ref{fig:system_architecture}.

\subsection{Relative Dynamics}
Relative translations between chaser and target spacecraft have been modeled using the Hill Clohessy Wiltshire (HCW) equations. The HCW provides a analytical description of relative dynamics in the local orbital reference frame and is employed by the guidance and control algorithms. Additionally, a set of higher-fidelity numerical propagation modules with further perturbation models (such as $J_2$ contributions) are included within the framework to provide an additional level for comparison and assessment of the analytic dynamics implementation and its numeric response.

\subsection{Target Attitude Dynamics}
In addition to translational dynamics we have added attitude motion of the targeted spacecraft. The target attitude is represented by the unit quaternions while its angular velocity are propagated using its rigid body dynamics. We did this so that the target body doesn't feel stationary. The resulting pose orientation is used for generating the 3D geometry and image measurements observed by chaser.

\subsection{Synthetic Vision}
The Synthetic Vision provides the artificial images of the camera from the propagated target state. The three dimensional geometric model is projected onto the image plane by means of relative target pose and camera intrinsic parameters, representing the target spacecraft.The image measurements acquired consists of 2-D keypoint location corresponding to pre-established 3-D points on the target. It is possible to apply a certain amount of controlled noise or correspondence outliers on these measurements in order to test in a systematic manner the performance of the pose estimator in the case of degraded visual observations.

\subsection{Relative Pose Estimation}
The implemented pipeline applies RANSAC--EPnP to recover the relative camera pose robustly. RANSAC selects minimal subsets of keypoint correspondences, discards inconsistent matches, and the surviving inliers are refitted with a final EPnP call to obtain the pose estimate. An optional nonlinear Gauss--Newton refinement of the reprojection error is additionally evaluated in isolation (Experiment B); it is not applied in the closed-loop pipeline used for end-to-end evaluation.

\subsection{State Estimation}
The implemented framework uses nonlinear Bayesian estimation techniques; it consists of a Multiplicative Extended Kalman Filter (MEKF) and Unscented Kalman Filter (UKF). The estimated state consists of the relative position and velocity as well as the target-relative attitude and angular velocity. The measurement gating in the MEKF utilizes the Mahalanobis distance to discard measurements that disagree with the predicted states.

\subsection{Guidance and Control}
The system uses either Linear Quadratic Regulator (LQR) or Model Predictive Control (MPC) strategy. The MPC utilizes an explicit thrust constraint, and also takes an approach-cone constraint at the terminal point approach phase. The control input command drives the relative dynamics model which update chaser state and the next observation is produced and given back to navigation through the perception navigation control loop.

\subsection{Closed-Loop Operation}
At each simulation step, the entire pipeline runs in the closed loop. First, the real spacecraft states are advanced by the dynamics model and the target state is turned into synthetic measurements from the camera. These measurements are then used to derive an estimate of the relative pose. Second, navigation state is obtained from the state estimator and fed to the controller, and the calculated control command is used to apply an effect on the chaser dynamics before going onto the next time step.
Through the closed loop, the perception errors are allowed to be incorporated naturally into navigation and control so that one can provide the complete autonomous rendezvous system to be evaluated, not just standalone algorithms.
